# **User Manual**
Student

Students use the Student Tracker system to clock in, clock out, and view their attendance summary.

Available Capabilities:
Clock In
Log in to the Student Tracker system.


Navigate to the Student Dashboard.


Click the Clock In button.


The system records the timestamp and your current location.


A confirmation message appears indicating that the Clock In was successful.
Clock Out
Return to the Student Dashboard.


Click the Clock Out button.


The system logs the Clock Out timestamp and appends it to your attendance CSV entry.


A confirmation message appears indicating that the Clock Out was successful.
View Attendance Summary
Go to the Student Dashboard.


Click the View Attendance Summary button.


The system generates a summary of all your recorded:


Clock In/Clock Out times


Total hours


Locations recorded


Daily entries


Your full personal attendance/timesheet summary will appear on the screen.


If desired, you may download the generated CSV file.


Professor

Professors and instructors use the system to generate reports for students and view aggregated attendance data. 

Available Capabilities:

Generate Report for All Students
Log into the Instructor Portal.


Navigate to the Attendance Reports section.


Click the Generate Full Report button.


The system compiles the attendance/timesheet data for all students.


A downloadable CSV report is generated.


If there are any issues with report creation, the error logging system alerts the instructor and stores details in the backend.
Search for an Individual Student
Go to the Professor Workflow section.


Locate the Search Bar at the top of the page.


Type a student's name into the search field.


The system filters and displays matching results.


Select the desired student to generate:


An individual attendance report


Clock In/Clock Out history


Calculated hours


Timesheet entries


Download the report if needed.
Instructor View of Student Attendance/Timesheets
From the Instructor Dashboard, select View Student Reports.


You may either:


View all students (full report), or


Use the search bar to find a specific student


A report is generated containing details such as:


Student’s attendance history


Time totals


Location logs


Any missing entries


Reports are available to download as CSV files.

Common Troubleshooting Instances

Instance 1: The Clock In or Clock Out button does not respond
Possible Causes:
The internet connection is unstable.


The page has not fully loaded.


The browser is blocking location permissions (if location is used).
Solutions:
Refresh the page and try again.


Ensure you have a stable internet connection.


When prompted, allow the browser to access your device’s location.


Try a different browser (Chrome recommended).
Instance 2: The professor’s search bar is slow or shows no results
Possible Causes:
The name is misspelled or incomplete.


The system is still filtering the list.


Network delay or high system use.


Solutions:
Try typing the first few letters of the student's name.


Wait a moment—results should appear within a short time.


Make sure your internet connection is stable.
Instance 3: I cannot log in to my account
Possible Causes:
Incorrect username or password.


The account type does not match the login portal (Student vs. Professor).


Session expired.


Solutions:
Re-enter your login credentials carefully.


Ensure you are using the correct login page.


Clear browser cache and try again.


Contact the system administrator if the issue persists.


Instance 4: The attendance times seem incorrect or missing
Possible Causes:
You may have forgotten to clock in or clock out.


The browser may have been closed before confirmation.


Time zone settings differ.


Solutions:
Double-check that you fully completed both Clock In and Clock Out actions.


Wait a moment for the system to process the timestamp.


Ensure your device time and timezone are configured correctly.
